# 모션 핸들 테스트

상단 `핸들 테스트` 메뉴 또는 단축키 `8`로 연다. 경로는 `#/racing`이다. 기존 부품 조작 제스처는 이 모드에서 실행하지 않는다.

## 사용 방법

1. 왼쪽 아래에서 카메라를 켠다.
2. 가슴 앞에서 두 손을 핸들처럼 벌린다.
3. `중앙 맞추기 / 다시 보정`을 누르고 편한 자세를 0.5초 유지한다.
4. 두 손을 잇는 선을 기울여 좌우 조향한다.
5. 양손 손가락을 펼치면 브레이크, 다시 가볍게 쥐면 자동 가속이다. 손을 펼친 채로도 조향한다.

## 인식 방식

- 실제 영상의 종횡비와 셀피 미리보기 반전을 보정한 손목 좌표로 기울기를 계산한다.
- 검출 순서에 의존하지 않으며, 두 손을 함께 이동하는 동작과 손가락 모양 변화는 조향에 영향을 주지 않는다.
- 신뢰도 0.6 이상인 손 두 개가 충분히 벌어져 있어야 유효하다. 손이 겹치거나 기울기가 75도를 넘으면 유효 입력으로 쓰지 않는다.
- 중앙 기준 ±5도는 직진, ±30도는 최대 조향이다. 지수 평활화로 떨림을 줄인다.
- 브레이크 변경은 120ms 유지해야 반영한다. 손을 놓치면 각도를 유지하며 감속하고, 마지막 유효 입력 후 1초가 지나면 시뮬레이션을 정지한다. 영상 프레임이 아예 멈춰도 화면의 시간 루프에서 정지를 처리한다.
- 속도는 입력 확인용 시뮬레이션이며 실제 레이싱 게임은 아직 포함하지 않는다.

## 실제 카메라 확인

- 수평에서 조향값이 0%이고 손을 함께 옮겨도 직진을 유지하는지 확인한다.
- 시계 방향으로 기울이면 화면의 핸들과 조향값이 오른쪽으로 움직이는지 확인한다.
- 기울기를 유지한 채 양손을 펼쳐도 조향각은 유지되고 속도만 줄어드는지 확인한다.
- 한 손을 가리거나 카메라를 끄면 감속 후 정지하는지 확인한다.
- 실제 웹캠 정확도는 사용 환경에서 별도 확인해야 한다. 자동 테스트는 합성 랜드마크로 방향, 종횡비, 동시 브레이크·조향, 보정, 떨림 방지, 추적 끊김 처리를 검증한다.
