# 창 구기기 데모

상단 `창 구기기`, 단축키 `0` 또는 `#/crumple`에서 연다.

## 카메라 조작

1. 카메라를 켜고 두 손을 펼쳐 창 양쪽을 잡듯 벌린다.
2. 열린 손을 250ms 유지하면 현재 손 간격을 기준으로 잡는다.
3. 손가락을 오므리며 두 손을 가운데로 모으면 창 표면이 점점 접히고 구겨진다.
4. 손 간격이 충분히 줄고 두 손가락 접힘의 평균이 50% 이상인 상태를 180ms 유지하면 종이뭉치가 완성되고 쓰레기통이 나타난다.
5. 확정 전에 손을 다시 벌리면 창이 다시 펼쳐진다. 손을 놓치면 닫지 않고 준비 상태를 초기화한다.

손 간격은 영상 종횡비와 손 크기로 보정한다. 손이 겹쳐 인식이 끊길 경우 조금 벌린 상태에서 손가락을 오므린다. `창 다시 펼치기`로 반복할 수 있다.

## 마우스 체험

`마우스로 체험`을 선택한다. 슬라이더로 중간 상태를 살펴보거나 `꾹 눌러 구기기`를 유지한다. `전체 효과 재생`은 약 2.1초 동안 구김 효과를 자동 재생한다. 완성 후 `슛 파워`와 `좌우 조준`을 조절하고 `슛!`으로 궤적과 명중 판정을 확인한다. 정면·100% 파워는 기본 골인 예시이며, 약한 슛·강한 슛·옆으로 빗나간 슛도 확인할 수 있다.

## 종이뭉치 던지기

1. 구김이 끝나면 한 손을 쥐어 종이뭉치를 잡는다. 오른손을 우선 선택하며, 오른손이 없으면 주먹을 쥔 왼손을 사용한다.
2. 잡은 손을 움직이면 종이뭉치가 따라온다. 움직임이 있으면 점선 예상 궤적을 표시한다.
3. 농구 슛처럼 위로 밀어 올리며 손가락을 펼치면 최근 약 170ms의 손 이동으로 파워와 방향을 계산한다. 주먹을 최소 120ms 유지해야 한다. 좌우 이동은 조준 편차, 위로 올리는 속도는 앞으로 보내는 힘으로 사용한다. 단순한 수평 스와이프는 슛으로 처리하지 않는다.
4. 천천히 손을 펴거나 손을 놓치면 던지지 않고 고정한다. 다시 같은 손을 쥐어 조작을 계속할 수 있다.
5. 중력 궤적으로 통의 입구를 통과하면 `골인`을 표시한다. 빗나가면 `종이뭉치 다시 줍기`로 재시도한다.

쓰레기통은 깊이 약 6의 가상 코트 뒤쪽에 배치한다. 종이뭉치가 완성되면 시점이 올라가며 바닥 격자·슛 라인·백보드가 나타난다. 기본 슛은 약 1.45초 동안 높은 포물선을 그린다. 손목의 깊이 추정 대신 위로 올리는 속도를 원거리 슛 파워에 매핑하며, 실제 농구의 거리·힘을 측정하는 기능은 아니다.

## 시각 효과

크롬처럼 그린 창 모형을 텍스처로 사용하고, 분할된 3D 종이 표면의 각 정점을 변형해 주름과 접힘을 만든다. 완성된 종이뭉치는 던지기 전까지 남아 있으며, 쓰레기통에 들어가면 사라진다.

실제 크롬 탭·창 종료 명령은 실행하지 않는다. 카메라 영상은 저장하지 않는다. 실제 웹캠 동작은 사용 환경에서 확인해야 한다.
