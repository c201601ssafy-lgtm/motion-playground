## 2. 지금까지 한 일

### 핵심 기능 (Phase 1~4)

- **기어박스 모델**: 8개 부품, 8개 결합 지점, 4단계. YAML로 정의하고 로더가 참조 무결성과 기어 중심 거리를 검사한다.
- **조립 엔진**: 9단계 규칙으로 판정하고 오류 8종을 낸다. 감속비 3:1이라 입력 30rpm이면 출력 10rpm이다.
- **3D 화면**: React Three Fiber. 마우스·키보드·손 입력이 하나의 Command 계층으로 모인다.
- **손 제스처**: MediaPipe 21개 랜드마크를 쓴다.
  - 집기(🤏): 잡기·이동·놓기
  - 손바닥(✋): 모델 회전
  - 주먹(✊): 취소
  - 추적은 32fps, 지연 p95는 37ms다.
- **모드 7개**: 연구실, 분해, 조립, 작동, AI 튜터, 실험 결과, 데이터 녹화.
- **AI 튜터**: Ollama의 qwen3:8b를 쓰고, 연결이 안 되면 Mock으로 바뀐다.
  - 도구 6개로만 엔진에 접근한다.
  - 근거 없는 숫자는 경고한다.
  - 도구 호출 평가는 75%에서 94%로 올랐다.

### 배포

- **CI**: GitHub Actions `ci.yml`이 push마다 ruff, pytest, tsc, vitest, build를 실행한다.
- **Pages**: GitHub Actions `deploy-pages.yml`이 main에 push하면 자동으로 배포한다.
  - 주소: https://jngbnss.github.io/holoforge-ai-lab/
  - 화면만 올라간다. 보기, 회전, 분해, 손 제스처는 된다.
  - 조립 판정, 작동, AI 튜터는 백엔드가 없어서 안 된다.

## 4. 로컬에서 실행하기

조립 판정, 작동, AI 튜터까지 전부 되는 방법. 터미널 두 개가 필요하다.

```bash
# 1) 백엔드
cd backend
uv run uvicorn app.main:app --port 8000

# 2) 프론트 (5173을 다른 프로젝트가 쓰면 포트를 바꾼다)
cd frontend
npx vite --port 5180 --strictPort
```

브라우저에서 http://localhost:5180 을 연다.

AI 튜터에는 Ollama와 `qwen3:8b`가 필요하다. 없으면 Mock 답변이 나온다.
