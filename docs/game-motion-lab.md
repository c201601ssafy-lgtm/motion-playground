# 게임 모션 실험실

상단 `게임 모션` 메뉴 또는 단축키 `9`로 연다. 직접 경로는 `#/motionlab`이다. 네 가지 게임 입력을 확인하는 작은 시뮬레이션이며 완성된 게임은 아니다.

| 게임 | 모션 | 확인할 반응 |
|---|---|---|
| 달리기 | 선택한 손의 검지와 중지를 번갈아 굽히고 펴기 | 검지→왼다리, 중지→오른다리, 걸음 수와 전진 |
| 항아리 | 선택한 팔로 망치 회전, 팔 뻗기로 길이 조절 | 망치 방향·접촉, 접촉 중 휘두르면 몸 상승 |
| 양궁 | 반대 팔로 조준, 선택한 손을 쥐고 당긴 뒤 펼치기 | 당김 힘, 발사, 비행·표적 명중·점수 |
| 레이싱 | 양손 손목 기울기, 양손 펼치기 | 핸들 조향과 동시 브레이크, 시뮬레이션 속도 |

## 시작

1. 게임을 선택한다.
2. 카메라를 켠다. 항아리·양궁은 양쪽 어깨, 팔꿈치, 손목이 화면에 들어오도록 뒤로 물러난다. 양궁은 당기는 손의 손가락도 보여야 한다.
3. 조종하는 손·팔을 선택하고 테스트를 시작한다.
4. 항아리는 편한 팔 방향에서 `현재 자세로 기준 보정`을 누른다. 양궁은 시위를 당기기 전의 손 사이 거리에서 보정한다. 레이싱은 `중앙 맞추기`를 누른다.
5. 동작과 판정 값을 보며 기준·힘을 조절한다. `일시정지` 후 기록을 다운로드한다.

카메라 없이 `예시 입력 (합성 모션)`을 선택하고 시작하면 동일한 판정 로직에 합성 관절을 넣어 흐름을 확인한다. 이 입력은 실제 인식 성능을 입증하지 않는다.

## 기록과 추적

- 최근 최대 1200개 샘플(약 60초), 상대 시간, 관절 좌표, 신뢰도, 게임 출력, 해당 시점의 설정을 JSON으로 내려받는다. 영상은 저장·전송하지 않는다.
- 실제 카메라와 합성 입력을 `source`로 구분한다. 최근 판정 메시지는 12개까지 포함한다.
- 손 추적은 기존 MediaPipe Hand Landmarker를 사용한다. 팔 입력 게임에서는 추가로 Pose Landmarker Lite를 약 15fps로 실행하고, 프리뷰에 상체 뼈대를 보라색으로 그린다. 게임 전환이나 카메라 종료 시 모델을 닫는다.
- 첫 모델 사용에는 네트워크 연결이 필요하다. 모델 로딩 실패는 상체 추적 상태에 표시한다.
- 입력이 250ms 이상 갱신되지 않으면 달리기·팔 게임의 조작을 멈춘다. 양궁은 추적 끊김을 발사로 해석하지 않는다.
- 달리기는 손가락 길이 대비 굽힘을 사용해 손 크기와 손바닥 이동의 영향을 줄이고, 두 손가락이 모두 접힌 주먹은 발걸음으로 세지 않는다.
- 항아리는 간단한 접촉·상승 시뮬레이션이다. 실제 항아리 게임의 전체 물리 엔진·난이도·맵은 포함하지 않는다.

## 실제 입력 확인 항목

- 달리기: 같은 손가락 반복·주먹은 걸음이 늘지 않고, 교대 동작에서만 걸음이 늘어나는지 확인한다.
- 항아리: 원을 그리는 팔 움직임에 망치가 연속적으로 따라오는지, 팔을 가려도 갑자기 튀지 않는지 확인한다.
- 양궁: 조준 팔이 흔들리지 않는지, 손가락을 잠깐 펴는 오인식이나 추적 끊김이 발사가 되지 않는지 확인한다.
- 레이싱: 손을 펼쳐 브레이크를 밟아도 조향각이 유지되는지 확인한다.

자동 테스트는 정규화·교대 발걸음·추적 끊김·팔 회전 경계·시위 유지·발사 중복 방지와 합성 모션 흐름을 검증한다. 실제 웹캠 인식률은 조명·거리·사용자별 기록을 통해 별도 확인한다.
