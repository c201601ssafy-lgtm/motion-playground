# Simulation Limitations

> 모든 작동·해석 화면에 다음 문구를 표시한다.
> **교육용 시뮬레이션이며 실제 설계·제조·안전 판단에 사용할 수 없습니다.**

## 디스플레이 표현

- 화면이나 투명 스크린의 3D 이미지는 실제 자유공간 홀로그램이 아니다.
- 프로젝터·투명 스크린 사용 시: "투명 디스플레이 또는 Pepper’s Ghost 방식의 홀로그램 유사 시각화".

## 기어 작동 표현

- 회전 방향·속도비는 이빨 수와 맞물림 관계로 계산한 **이상적인 기구학 값**이다(`AssemblyEngine.mechanism_state`).
- 마찰, 백래시, 탄성 변형, 관성, 효율 손실은 고려하지 않는다. "토크 3배"는 손실 없는 이론값이다.
- 기어 치형은 사다리꼴 근사이며 인벌류트 치형이 아니다.

## 게임 물리 (Rapier)

현재 쓰는 곳은 하나다. 규칙 엔진이 틀렸다고 판정한 부품이 튕겨 떨어지는 연출(P5-5). 부품은 경계 상자 하나로 근사하고, 질량·마찰·반발 계수는 보기 좋게 고른 값이다. 판정은 이미 끝난 뒤에 재생하므로 결과에 영향을 주지 않는다.

Rapier는 사용자 조작, 충돌 표현, 교육용 동작 시각화, 조립 결과 확인에만 쓴다. 다음을 주장하지 않는다.

- 실제 응력값
- 실제 유체 흐름
- 실제 피로 수명
- 실제 누수량
- 안전 인증 수준의 해석

## 조립 판정

- 판정은 규칙(거리, 축 각도 15°, yaw, 순서, 부모 부품)으로만 한다. 실제 공차·끼워맞춤은 다루지 않는다.

## 공학 해석 확장 (MVP 이후)

- CalculiX/OpenFOAM 결과는 해석 도구의 출력 파일만 사용한다. AI는 값을 생성하지 않고 설명만 한다.
- 입력값, 단위, 경계 조건이 없으면 결과를 제공하지 않는다.
