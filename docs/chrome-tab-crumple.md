# 실제 크롬 탭 선택 · 구겨서 닫기

Chrome 확장 프로그램과 기존 창 구기기 페이지를 연결한다.
확장 프로그램의 탭 목록에서 고른 탭 하나만 골인 후 닫는다.
탭을 실제로 변형하는 것이 아니라 체험 페이지에 종이 애니메이션을 보여준다.
체험 페이지와 나머지 탭은 유지된다. 빗나가면 공이 돌아오고 대상 탭은 유지된다.

## 설치와 사용

1. 최신 프론트엔드 변경을 GitHub에 올려 Pages 배포를 완료한다.
2. 데스크톱 Chrome에서 `chrome://extensions`를 연다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택한다.
4. 프로젝트의 `chrome-extension` 폴더를 선택한다.
5. 크롬 도구 모음에서 Motion Playground 확장 프로그램을 누른다.
6. 구길 탭을 선택하고 **선택한 탭 구기기**를 누른다.
7. 열린 체험 페이지에서 카메라를 켠다. 검지만 펴서 탭 카드를 가리키고 잠깐 유지한 뒤 엄지·검지를 집어 선택한다. 마우스 클릭으로도 선택할 수 있다.
8. 선택이 끝나면 양손으로 구겨 던진다. 골인하면 대상 탭이 닫힌다. 구기기 화면의 **다른 탭 선택**으로 돌아갈 수도 있다.

로컬 개발에서는 팝업의 체험 페이지를 **로컬 개발 페이지**로 선택하고
기존 `npm run dev` 서버를 localhost:5173에서 실행한다.
공유 페이지 기본 주소는 https://c201601ssafy-lgtm.github.io/motion-playground/ 이다.
주소를 바꾸려면 manifest의 externally_connectable, background.js의 SITES,
popup.html의 선택 항목을 함께 수정한다.

## 선택과 표시

일반 HTTP/HTTPS 탭을 선택할 수 있다. 확장 프로그램을 누른 시점의 활성 탭은
가능하면 현재 보이는 화면을 한 번 캡처해 종이 표면으로 사용한다.
다른 탭을 선택하거나 캡처가 불가능하면 탭 제목을 넣은 모형으로 표시한다.
체험 페이지의 탭 카드에는 제목이 표시되며 검지 커서와 강조 표시로 대상을 고를 수 있다.
선택 중에는 구기기 동작을 해석하지 않는다. 선택한 제목은 구기기 단계에서도 표시된다.
목록은 확장 프로그램을 실행할 때 같은 크롬 창에 열려 있던 탭으로 한정된다.
새로 연 탭을 선택하려면 확장 프로그램에서 다시 시작한다.
브라우저 설정 페이지나 확장 프로그램 내부 페이지는 선택하지 않는다.

## 연결 범위

선택한 탭 ID와 주소, 새로 열린 체험 탭 ID, 임의 세션 토큰을 묶어 연결한다.
대상 탭의 주소가 바뀌거나 30분이 지나면 닫기 요청을 거부한다.
다른 탭이나 iframe에서 보낸 요청도 거부한다.
한 번 닫은 세션은 다시 사용할 수 없다. 다른 탭을 닫으려면 확장 프로그램에서 다시 선택한다.
캡처는 확장 프로그램의 세션 저장소에 임시 보관되고 체험 페이지에 브라우저 메시지로 전달된다.
캡처 이미지를 서버로 업로드하는 코드는 없다.

Chrome 웹 스토어에 배포된 제품이 아니라 수동 설치하는 개발용 확장 프로그램이다.
GitHub Pages 링크만 공유해서는 실제 탭을 닫을 수 없으며 참가자도 확장 프로그램을 설치해야 한다.
실제 설치·카메라 권한·탭 닫기 확인은 데스크톱 Chrome에서 진행해야 한다.
