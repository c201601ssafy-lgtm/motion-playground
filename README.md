# HoloForge AI Lab

웹캠 손동작으로 3D 기어박스를 분해·조립하고, AI 튜터가 부품의 역할과 작동 원리를 설명하는 제스처 기반 공학 체험 서비스.

> 투명 디스플레이 사용 시 표현: "투명 디스플레이 또는 Pepper’s Ghost 방식의 홀로그램 유사 시각화". 실제 자유공간 홀로그램이 아니다.
> 교육용 시뮬레이션이며 실제 설계·제조·안전 판단에 사용할 수 없습니다.
